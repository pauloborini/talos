### DEC-050 — Identidade dos produtos do ecossistema

`Atlas Agents` é o produto (hub/app final, que absorve os demais); `Argus`, `Talos` e `Athena` são módulos com codinome mitológico próprio. `Atlas` não se repete como prefixo em nomes técnicos — server name, tool prefix, skill prefix, bin CLI, pacote npm e plugin. Exceção: `atlas-agents` mantém o nome.

Mapeamento fechado: `Argus` = code retrieval e context packing local (repo `atlas-cortex`); `Talos` = pipeline determinística (este repo); `Athena` = documentação e conhecimento contínuo (repo `atlas-brain`).

Motivo registrado na origem: múltiplos MCPs com `Atlas` no nome faziam o agente confundir qual produto usar — colisão conceitual, não técnica.
